## Key Privacy Principles Enforced in Code

1. **Zero Full-Code Storage**: SkillVerse does **NOT** clone or retain full source code repositories on its servers. Only structural AST manifests (package dependencies, folder trees, README markdown) under 500KB thresholds are inspected in-memory during analysis.
2. **Deterministic Credibility Decoupling**: Payment status has **0.0%** impact on Trust Scores or DCC levels.
3. **Strict Tenant Boundaries**: Company recruiter notes and candidate shortlists are never accessible across organizations.
